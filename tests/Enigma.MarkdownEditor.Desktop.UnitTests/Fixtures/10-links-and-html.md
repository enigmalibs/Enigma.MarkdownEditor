# Links

An inline link to [the docs](https://example.com/docs), and one with a title
[like this](https://example.com "hover me"). Both open in the browser, and the pointer is a hand
over the label and an arrow either side of it.

An autolink in angle brackets: <https://example.com/angle>

A bare address the autolink extension picks up: https://example.com/bare

A link inside **emphasis, [which is still clickable](https://example.com/nested)**, and one after a
hard line break  
[which is also still clickable](https://example.com/after-break).

A relative link to [another note](./other-note.md), which opens in a tab — the same way the file
tree opens one. A relative link with an anchor, [like this](./other-note.md#a-heading), opens the
file rather than looking for a file named after the anchor.

A link into this document, [#links](#links), does nothing yet: there is nothing to scroll to until
the view modes arrive.

A relative link to something that is not a note, [a spreadsheet](./budget.xlsx), goes to whatever
the operating system opens it with.

Raw HTML, which v1 shows as the text it was written as:

<div class="callout">Not rendered as a div.</div>

An inline <b>bold tag</b> in a sentence.
