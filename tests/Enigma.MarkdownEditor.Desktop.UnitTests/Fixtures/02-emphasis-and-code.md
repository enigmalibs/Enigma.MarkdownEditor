# Emphasis

Plain text, then **bold**, then *italic*, then ***bold italic***, then ~~struck through~~, then a
`code span` in the middle of a sentence, then back to plain text.

A sentence that ends on a code span: `dotnet build --no-incremental`

Nested: **bold with *italic* inside it** and *italic with **bold** inside it*.

Underscores work too: __bold__ and _italic_.

A hard break at the end of this line,  
so the next one starts underneath it rather than flowing on.
